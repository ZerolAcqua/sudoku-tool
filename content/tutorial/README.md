# 前言

这是一本**数独解题技巧**教程。每一篇都配有可播放的盘面演示：盘面下方的控制条可以逐步查看推理过程，
自动播放时会在各步骤之间循环。

## 如何阅读

- 左侧是全书目录，当前文章下会列出本篇的小节，随阅读位置高亮。
- 每篇末尾有「上一篇 / 下一篇」，按目录顺序阅读即可。
- 灰色、标着「筹备中」的条目还没有写完。

建议从 [唯余法](basic/naked-single.md) 开始，它是所有技巧的基础。

## 一个演示

下面的盘面会自动播放，演示 [宫摒除](basic/box-hidden-single.md) 的思路：

```sudoku
puzzle: ....8.......5.2.....3...1...5.....2.8...9...66..375..9.15.2.83.....5.......739...
frames:
  - caption: 第 2 宫还没有 3。
    highlight: b2
  - caption: 第 3 行、第 4 列、第 5 列都已经有 3。
    lines:
      - { from: r3c3, to: r3c6 }
      - { from: r6c4, to: r1c4 }
      - { from: r9c5, to: r1c5 }
  - caption: 3 只能填在 r1c6。
    place: r1c6=3
```
